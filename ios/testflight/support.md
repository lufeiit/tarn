# FlowArc Support

FlowArc is a VPN client for iOS. It does not offer servers, subscriptions, or accounts. To get started, open **Profiles**, add a subscription URL or configuration file, or create your own configuration. Select the profile, return to the dashboard, enable **VPN**, and approve the iOS permission prompt if shown.

- **Cannot import a profile?** Check that the file is a supported YAML configuration or that the URL downloads one directly. Ask the profile provider for a fresh link if it has expired.
- **Cannot connect?** Check your internet connection and verify the server, port, credentials, and TLS certificate match your configuration. Contact the server provider for service issues.
- **Want to disconnect?** Turn off VPN from the dashboard or iOS Settings.

Email [SUPPORT_EMAIL] for app support. Include your iOS version, FlowArc version, and what happened. Do not send passwords, private subscription URLs, or unredacted logs.
